## 📝 Descrição do Projeto
O **TaskTracker** é uma aplicação em linha de comando (CLI) desenvolvida em Python para auxiliar estudantes e profissionais na organização e acompanhamento de suas atividades diárias. O sistema permite cadastrar tarefas com títulos, descrições, níveis de prioridade e datas limite, além de listar todas as pendências de forma clara e estruturada.
